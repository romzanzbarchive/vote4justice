# Vote4Justice
1. supabase.com এ ফ্রি প্রজেক্ট খুলুন → SQL Editor এ `supabase.sql` Run করুন।
2. Project Settings > API থেকে URL ও anon key কপি করে `config.js` এ বসান।
3. GitHub এ নতুন repo খুলে সব ফাইল আপলোড করুন।
4. vercel.com > Add New Project > repo ইমপোর্ট > Deploy (Framework: Other)।
নতুন জরিপ: Supabase Table Editor এ `polls` ও `options` এ সারি যোগ করুন। ফাঁকা config.js = ডেমো মোড।
